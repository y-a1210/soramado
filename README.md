# SORAMADO マイクロワールド

研究用の架空OTA UIプロトタイプです。

## GitHub Pages 公開方法

1. このフォルダ内の `index.html` と `.nojekyll` をGitHubリポジトリのルートにアップロードします。
2. GitHubの `Settings` → `Pages` を開きます。
3. `Source` で `Deploy from a branch` を選びます。
4. Branchを `main`、Folderを `/(root)` にして `Save` します。
5. 公開後、`Visit site` からURLを確認します。

## 注意

- GitHub Pagesは公開サイトです。個人情報や秘密鍵、APIキーを入れないでください。
- 本HTMLは単体で動作します。
- ログ送信先 `endpoint` は既定で空欄です。外部送信を使う場合のみ設定してください。
